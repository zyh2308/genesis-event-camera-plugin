# Repository scope and reproducibility

## Included

This repository contains the independent `physics/radiance v2` event-camera
plugin for Genesis:

- explicit linear-radiance and sRGB-fallback paths;
- Genesis camera/link pose adapters;
- SE(3)-based depth-aware bidirectional warp;
- adaptive temporal sampling;
- NumPy and Torch/CUDA reference implementations;
- DVS pixel model, noise presets, recording utilities and tests;
- an optional Genesis 1.2.2 renderer overlay for scene-linear HDR output.

## Deliberately excluded

The following are outside this repository and must not be silently copied into
it:

- the original/direct baseline plugin;
- WAM/Dreamer/DreamerV3 training jobs;
- generated HDF5, video, event or checkpoint data;
- server-specific credentials, logs and paths;
- a claim that the nominal EVK4 profile is a calibrated sensor model.

## Renderer overlay

`integrations/genesis_renderer_hdr_v2_overlay/` contains only the modified
Genesis renderer files and smoke tests. It is not a complete Genesis source
distribution. Apply the overlay to a matching Genesis 1.2.2 source tree in a
separate environment, then use:

```python
rgb_linear, depth, seg, normal = camera.render(
    rgb=True,
    depth=True,
    segmentation=True,
    normal=True,
    radiance=True,
)
```

The HDR path is opt-in. The standard Genesis installation and the direct
baseline must remain unchanged.

## Scientific status

The repository is a research prototype, not a completed EVK4 reproduction.
Before making a fidelity claim, record the Genesis version, renderer backend,
camera profile, radiance input domain, sensor parameters, resolution,
trajectory, random seed, and whether raw events were generated by direct
rendering or interpolation.
