Keep the original Catch It policy checkpoint and the frozen sparse event generator unchanged. Work from result commit `2f1332f`; the previous44 and72 episodes remain intact. A paper can focus on a clearly defined condition where the method helps. All seeds within that condition, and unsuccessful exploratory settings, remain in the evidence ledger.

Two independent local reviews found no coordinate/sign/dt bug in the current velocity bridge. Differencing consecutive noisy position estimates is not a verified repair. Contact-after-flight model switching and motion acquisition deserve direct inspection.

Primary hypothesis: at25Hz, fixed startup/association limits may prevent motion acquisition even when useful event contours exist. Inspect c02 and replay its actual cached events under causal availability; distinguish missing contours from valid contours rejected by a static-target association gate. A shared estimator change is permitted only after a concrete rejection is reproduced, with stationary and direction-reversal controls. Any candidate applies identically to both sources. Check all eight existing25Hz episodes, then fix the candidate before fresh seed validation; existing seed rescues are development results.

First perform a renderer-only grid on archived physical states, before any new catch outcomes: front point lamp at(0,-0.5,2.5)m, intensity0/25/100/400/1600 in renderer units, release-relative times.05/.20/.40s. No physics step, fake LDR attenuation, target mask supplied to control, or change to the shader/core.

Initialization uses one actual shared RGB-D frame. A constant overexposed scene can break that common initializer; a subsequent dynamic-light protocol therefore requires an explicit public-time lamp schedule and checks for event bursts/false acquisition. Select a light regime using information-loss and visibility measurements, then test it with paired episodes. Native V2E supports other HDR modes: any gain against the current SSM39+uint8LDR path must be described at that scope, not as a universal limitation of V2E. A numeric threshold.2 in differently encoded inputs is not real-device response calibration.

Shared inputs/environments stay read-only, results use a new run directory. Check core/policy hashes before and after.
