# 条件优势复验与暗光位姿定位 Implementation Plan

**Goal:** 复核已有条件优势，并用同预算配对短检检验目标支持辅助监督是否改善暗光定位和完整位姿。

**Architecture:** 两条独立任务并行：冻结 RAW C1 在32条新共享物理轨迹上只推理；训练期增加可见物体 mask 辅助头，仅更新原中心分支。重建和光流保持原队列，仿真器、噪声、事件重放、正式门槛及推理读出均不变。

**Tech Stack:** 冻结 Genesis/EventGenesis/V2E、PyTorch、HDF5、既有受控 GPU3/GPU4 队列、CPU 几何评分、SHA256 收据。

## 1. 优势复验（GPU4，零训练）

- 执行前注册32个新物理 seed，并核对3个已登记银行的实际场景 seed 不重叠。复用原物理生成器和冻结传感器规则，不按预测选择轨迹。
- 正常、半亮为两个 primary；最暗强制报告。固定 RAW C1 两方法×三 seed；不同光照不切模型。
- 32条几何生成、三照度×两生成器事件重放后，先复算原18格 baseline，再评分新库存。保留原可见性排除规则和所有事件空窗，不补抽。
- 完整位姿 ADD-S 成功率为 primary。以轨迹为成组单位，先平均三 seed 配对差，10,000次 bootstrap；两个 primary 各用97.5%区间，且各自三 seed 差均为正才判条件优势成立。
- 若失败，如实结束该次确认；不得根据新结果调 mask 辅助短检或更换 seed、模型、条件。结论限定独立合成条件，不能替代真实泛化。

## 2. 暗光错峰定位（CPU，只读）

- 原1152预测与384个独立事件支持窗口全量核对：原生峰点、16格重叠、端点/起止并集支持分别统计。
- 对28个真正脱靶峰核原始表面ID；不把渲染区域当作逐事件来源或噪声分类。
- 固定原预测旋转与已存GT中心crop旋转，交叉替换中心和深度做几何诊断。GT oracle 不能输入部署模型，不解释为已经获得的准确率。

## 3. 前景辅助短检（GPU3，预算已锁）

- 仅采用已注册单一方案：中心主干增加训练期1×1 mask head；可见 mask 是共享合成标签。类平衡 fractional BCE，系数1。独立初始化不消耗原训练 RNG。
- 输入保持 RAW 三通道、原全局期望读出；mask 不进入模型输入、裁剪或推理加权。原 size、depth、rotation 固定。
- 实际服务器CPU15项通过后，核GPU3 UUID、父队列身份、单卡可见性和占用者；复算原18格完整baseline，不通过即零更新停止。
- 两方法 seed0 各1更新 smoke；核全部6组288步样本/增强 tape、共享标签、真实梯度、模型/辅助头/Adam独立读回。smoke退出0并收据绑定后才进入 study。
- study 两方法×三 seed×288更新，总1728；复用严格核验的同预算 RAW C1 控制，原中心阶段36项和匹配正常12项分别报告。它们不替代原正式30＋8门槛。
- 任何合成回退均保留，不以单个有利场景/seed采用候选；不启动长训、不打开新真实评分。需要独立新合成确认时，在旧64窗选择方案后再单独注册，不能使用上述优势确认集调参。
