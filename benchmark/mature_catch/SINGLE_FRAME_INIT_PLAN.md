# 2026-11-07 单帧初始化方案

用户已批准采用图像初始化、后续事件跟踪；方向分歧优先参考已有论文与代码，不先自行发明完整任务。

依据：EKLT（IJCV 2019）与 Data-Driven Feature Tracking for Event Cameras（CVPR 2023）支持图像建立参考、事件提供高频跟踪的技术路线。此处复用的是这种输入协议，不宣称直接复现两篇论文的算法。

保留原 Catch It! 机器人、原 PPO 权重、动作接口、物理任务和成功评分。已知尺寸球体是用户批准的首版对象。

每集只读取一次原相机实际 RGB 图像，由圆轮廓与已知半径求位置，不接收对象 GT、分割或深度。第一帧在该集配置的灯光下捕获，三条件均执行同一检测规则；不静默用正常光照替换逆光初始化。初始化失败作为结果保留。

之后不再读取 RGB。静止阶段保留初始世界坐标与零速度预测；事件测量通过相机自身姿态补偿，在检测到目标运动后切换到带测距不确定性的因果运动滤波。运动切换不读取仿真释放标记。事件使用冻结的 100 Hz 稀疏 HDR 重建路径，理想响应参数不改。

先检查正常与逆光初始化，再用 seed 1702 的正常 1.7 m/s、高速 2.2 m/s、高速逆光三条件实际闭环。保存失败与成功、完整 trace 和事件。补单帧初始化但不更新事件的对照，避免把初始化效果误称事件贡献。当前为开发可行性，不做生成器排名。
