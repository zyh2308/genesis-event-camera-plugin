# 成熟接取任务：首条事件跟踪接取成功

2026-11-07，开发阶段记录；后续复测结果另行补充。

## 已经做到什么

在 g3 实际运行 Genesis，用 Catch It! 的原机器人、原接取权重和原任务评分，完成一条“初始单帧 RGB + 后续事件跟踪 + 原机器人自身状态”的接取回合。事件仍来自已冻结的 100 Hz 稀疏 HDR 重建路径，没有改用高频 Direct-HDR，也没有改事件核心。

| 条件 / 开发回合 | 原任务成功 | 首次手部接触 | 结束时间 | 底盘最大位移 |
|---|---|---|---|---|
| 正常照明，水平来球 1.7 m/s；hybrid_normal_v9 | 是 | 1.40 s | 2.52 s | 0.938 m |
| 正常照明，水平来球 2.2 m/s；hybrid_fast_v9 | 否 | 1.36 s | 1.52 s | 0.467 m |
| 强背光，水平来球 2.2 m/s；hybrid_backlit_v9 | 否 | 无 | 1.262 s | 0.776 m |
| 同一正常来球，仅初始图像、不更新事件；initial_frame_only_normal_v9 | 否 | 无 | 1.458 s | 0.760 m |

这些是同一已知开发来球的条件试验，不能换算成总体成功率。此前同条件开发回合曾失败，尚未证明稳定重复性。高速失败仍保留，不能只展示成功。

成功回合从 1.40 到 2.52 s 的 29 个控制记录均检测到手部接触。接触前 19 次运动状态查询（含短时预测）的像素位置误差中位数 1.93 px、P95 为 4.70 px；其中 14 次有近期事件观测。这不代表整集都由新鲜事件定位，接触后按手部自身状态传播已估计的持握位置。

## 没有混淆的事项

- 原模型复用，不是训练出了一个新的事件感知网络；当前感知前端是已知球尺寸下的几何估计与因果运动滤波。
- 控制器不读取球真值、深度或分割标签。插件内部重建使用的几何信息与下游控制输入分开。
- 保持阶段使用手部自身状态，1.41 s 后停止不再参与控制的事件采样；不能把后半程称为连续视觉跟踪。
- “只保留初始图像”是输入更新消融，超过状态期限会停控，不是完整 RGB 视频跟踪基线。
- 尚未进行 Ours/V2E 合成训练数据比较，也没有证明真实低照度或实物传感器性能。

## 版本核对发现

v9 的入口是指向 v8 的符号链接，导致实际模块加载与计划的前景轮廓候选版本不一致；初始化输出仍符合旧模块。成功物理轨迹和输入记录有效，但不得将它归因于新轮廓算法。

已准备无符号链接歧义的隔离源代码，并在实际传感器构造后写入逐模块路径和 SHA256 收据，重新验证候选。部署预检中断单独记账，不混入物理回合失败率。
