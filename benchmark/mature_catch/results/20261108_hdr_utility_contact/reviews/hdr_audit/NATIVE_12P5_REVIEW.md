# 12.5Hz原生V2E接口复核：已完成范围

依据：`native_parity12p5/V2E_PARITY_RECEIPT.json`。这是g3上的实际接口一致性检查，不是12.5Hz机器人闭环结果。

| 检查 | 实测结果 |
|---|---|
| 原生输入 | 三张已归档、实际renderer uint8灰度端点，时刻1.00/1.08/1.16s |
| 端点间隔 | 80ms，即12.5Hz |
| 插帧配置 | 每区间80个子帧，配置最大间隔1ms |
| 对比子帧 | 160帧；uint8最大差0 |
| 对比事件 | 23,334条；坐标/极性一致，时间最大差0 |
| 运行 | PASS；wall 7.512s |

检查使用同一SSM39 checkpoint和官方V2E源码，receipt中保留了source、checkpoint、fixture SHA。图像和事件的精确一致支持流式接入保持此配置的原生算法行为，不能说明它对真实传感器准确、不能说明Ours优于V2E，也不能直接推断12.5Hz抓取成功率。

12.5Hz物理闭环尚未运行。此前原整包检测只有80ms一次的观测，而运动确认要求50ms内两次一致检测，存在接口节拍冲突；把允许间隔直接改成100ms并非论文规定值。当前主线改为在原包可用后处理10ms子窗，原50ms规则不变，但本次实际闭环仅验证25Hz源图像。

所有配置、GPU身份、源图像时间、原生文件及数据哈希见receipt。原始大fixture仍在服务器，不重复拷入仓库或桌面。
