# 当前闭环实验能否成为正式论文结果：文献核查与最小补实验方案

日期：2026-11-08。本文分析的是复用Catch It!原策略的移动机械臂接球实验，不涉及A反弹板、B柔性条带、C流体实验，也不把其他会话的sim-to-real结果计入本任务。以下补实验是研究建议，尚未运行。

## 核心判断

现有结果适合作为可行性验证和失败分析。要成为事件仿真器论文的主要闭环证据，最重要的缺口是：尚未在同一任务上与其他事件生成方法比较，其次是样本太少、压力条件的含义尚不够明确。3/6本身不是不可发表的数字；关键是它对比谁、差异有多稳定、为何产生差异。

保持现有任务、7°机位、原策略与冻结核心，把精力集中在公平对照和可解释结果上，比继续追求更复杂的演示场景更直接。

这个任务本身已经有分量：移动底盘、机械臂、灵巧手要协调，飞行、真实碰撞、接触后留住都影响结果。本批普通组底盘最大位移约0.45–1.48m，已不再是机器人几乎不动的展示。当前主要证据缺口是比较设计，不是必须再换一次场景。

## 一、相关论文实际验证了什么

| 论文与原始资料 | 与本实验直接相关的做法 | 对我们的启示 |
|---|---|---|
| [Catch It!，ICRA 2025项目官方仓库](https://github.com/hang0610/Catch_It)、[论文§V与表I/II](https://arxiv.org/html/2409.10319v1) | 分开统计手掌碰到目标与把目标保持至回合结束；改变来球和物体条件，配有方法对照 | 成熟任务和原权重可以继续复用；不能把一次接触当作完整抓住 |
| [Event-based Agile Object Catching，ICRA 2023，§V](https://arxiv.org/html/2303.17479v1)、[官方代码](https://github.com/uzh-rpg/event-based_object_catching_anymal) | 按速度与侧向偏移分析；把感知预测正确与实际接取分开；明确可操作范围 | 报告成功率之外，还要说明失败发生在感知还是接触保持环节 |
| [Video to Events，CVPR 2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Gehrig_Video_to_Events_Recycling_Video_Datasets_for_Event_Cameras_CVPR_2020_paper.html)、[官方代码](https://github.com/uzh-rpg/rpg_vid2e) | 用合成事件训练视觉网络，并检验真实事件上的识别与分割 | “可以在线驱动固定策略”与“适合训练、可以迁移”是不同证据；本轮只完成前者 |
| [v2e，CVPR Workshops 2021，§3与§6](https://arxiv.org/html/2006.07722v2)、[官方代码](https://github.com/SensorsINI/v2e) | 明确建模弱光下噪声与响应变慢，并在真实日/夜数据上检验下游任务 | 把灯调暗、仍使用理想无噪声事件响应，不足以证明真实弱光性能 |
| [ESIM，CoRL 2018，§5](https://proceedings.mlr.press/v87/rebecq18a/rebecq18a.pdf) | 合成数据训练的光流网络再在真实事件上评估 | 训练数据效用需要独立于自身训练事件的评价，不能只看本域拟合 |

原Catch It!表I报告200×64次仿真评估，真人实验总计160次。事件四足接球论文报告22次可行范围内的真实投掷。**这些不是论文统一规定的最小样本数，也不能拿真实机器人试验数量直接充当仿真实验标准**；它们说明实验规模应与结论强度、资源成本和对照设计一起考虑。[Catch It!](https://arxiv.org/html/2409.10319v1)、[事件接球](https://arxiv.org/html/2303.17479v1)

## 二、最关键的不足：没有证明“我们的仿真器更有用”

目前3/6、3/6、2/6与6/6、5/6、5/6的对照，回答的是感知接入后损失了多少任务表现。它不回答Ours与V2E谁更好；真值状态也不是事件仿真器的竞争方法。

正式主表建议沿用已选方法：Ours、V2E、Vid2E、FILM+事件响应、RIFE+事件响应。FILM和RIFE是中间帧生成方法，必须接上明确记录的事件响应后才能作为完整输入链参与接取，不能直接把插帧器称为事件仿真器。Vid2E官方仓库现在已经支持FILM，因此要固定版本、明确“原论文Super-SloMo配置”与“FILM替换配置”的区别，避免把同一路径当作两个独立方法。[Vid2E官方仓库](https://github.com/uzh-rpg/rpg_vid2e)

时间有限时先完成Ours/V2E配对，作为决定是否扩展全部方法的依据。各方法共享场景、相机、来球、首帧RGB-D、估计器、原策略和判据。各生成方法按自身原生接口获取输入：Ours保留线性HDR与几何支持，视频方法使用其支持的图像编码，并公开编码/曝光与额外场景信息。不能为了统一输入而把Ours再次降成显示灰度；也不能事后只为某个方法挑有利曝光或参数。

如果主张中间重建本身更好，可额外用共同像素响应隔离重建差异，但必须标注为受控比较；不能把关闭v2e非理想模型的设置写成它完整的默认传感器模型。完整系统结果与机制解释应在报告中讲清楚。

还应检查配置去重：如果V2E与Vid2E都换成相同插帧器、相同灰度变换和相同理想事件响应，它们可能退化为近乎同一路径。此时应合并或说明真正剩余的差异，而不是凑出五行方法。也不应让Ours使用理想无噪声响应，却以V2E加入真实噪声后的低成功率证明Ours的重建更好。

对闭环还有一个统一要求：插帧如果需要区间末端图像，就应等该图像实际采到后，才能把该区间事件提供给控制器。旧事件的时间戳不代表它早已可用。所有方法分别记录观测产生时间、数据可用时间和控制生效时间；实际计算慢而暂停模拟时间时，按离线因果仿真实验报告，不能声称已达到真实机器人实时控制。

## 三、六个seed只能提供很粗的成功率估计

目前每种条件只有六个独立新seed。3/6的Wilson 95%区间约18.8%–81.2%，2/6约9.7%–70.0%；这两个结果不能可靠区分普通、高速、逆光的难度。三种条件复用同六个seed，不能把18条当成18个独立样本缩窄置信区间。

建议正式测试先预先固定30–50个新seed，所有方法、三种条件配对运行。这个数量是根据当前资源和所需稳定程度提出的工作建议，不是CVPR或机器人学界的硬性要求；是否足以区分方法，取决于真实效果差与成对结果。最终报告成功率及区间，并按完整seed块做成对重采样比较，保留方法间相关性。相关统计实践可参照[rliable](https://github.com/google-research/rliable)。

正式测试前把改进后的估计器和参数固定。当前六个seed如果被用于进一步排查和调参，就转为开发数据，不能反复调好后仍称它们为独立测试。[Cawley与Talbot，JMLR 2010](https://www.jmlr.org/papers/v11/cawley10a.html)

这里的seed是测试回合随机种子，不是重新训练策略的种子。本轮原策略权重固定，增加测试seed即可检验当前链路的回合泛化；只有新增了感知网络训练，才另需多个训练seed与同等预算。

## 四、“高速、逆光”需要用量化描述建立说服力

当前普通组水平初速1.5/1.8m/s，总三维初速约2.57–3.83m/s；高速组水平初速2.0–2.4m/s，总三维初速约3.09–4.22m/s。不同seed竖直速度不同，总速度范围有重叠。因此主文应明确这是相同seed内增加水平初速的配对条件；当前不足以仅凭名字宣称极高速或达到其他平台的速度水平。

其他事件接球系统曾在不同平台、工作范围与末端装置下测试5–15m/s投掷；这可以帮助解释速度尺度，不能直接比较其成功率或要求灵巧手任务复制同样速度。[事件接球论文§V](https://arxiv.org/html/2303.17479v1)

比继续把数字调大更有价值的是报告球在实际控制相机中的像素速度、可观察时间、球的成像尺寸，以及接取策略还剩多少反应时间。这些量能解释当前速度对视觉究竟有多难。以保持较高参考可接性的范围为任务边界，不要让机器人机械能力的失败掩盖感知差异。

**完整数据补充后，这一点比预期更重要。** 六个普通回合的接触前画面运动中位数约375–477px/s，高速约386–470px/s；逐seed高速/普通之比约0.97–1.06，视觉中位运动并没有随水平初速明显加快。这里统计相邻10ms端点中球心均在画面内的位移，并包含机器人自身运动；尾部速度有所变化，不能把中位数不变理解为所有难度都相同。但当前“高速”确实更像水平发射速度的处理条件，尚未充分隔离高速视觉优势。

后续若要强化这项结论，应在原任务可接范围内预设更明显的横向运动或缩短有效观察窗口，再用像素速度和剩余反应时间定义压力等级。先用开发回合确认机械策略能完成，再固定新测试清单；不能按Ours成功与否选择来球。当前锁定批次不因这项发现而改参数或重写条件名称对应的数据。

当前逆光与高速逐条配对，这是优点；但光源设置尚无绝对照度标定，事件模型理想无噪声。正式可称“高对比逆光渲染条件”。如要进一步宣称抗过曝，应记录固定曝光/色调映射下目标区域的亮暗分布、裁剪比例，以及相应图像输入方法的表现。目标区域真值掩码只用于离线统计，不送入估计器。

如果要宣称弱光传感器优势，则要另外验证弱光响应、噪声与有效延迟；均匀降低亮度并不等于真实事件相机的弱光难题。v2e对此有专门的物理解释及任务实验。[v2e§3.1–3.3](https://arxiv.org/html/2006.07722v2)

## 五、指标应同时解释“看得准”和“接得住”

建议论文主表仅保留少量指标，按普通/高速/逆光列出完整接取成功率；另设感知与失败分析图，不把几十个工程字段放主表。

| 指标 | 定义与用途 |
|---|---|
| 完整接取成功率↑ | 主指标。沿用原任务保持至回合结束的规则，核验真实接触与末端保持；所有回合计入分母 |
| 真实接触率↑ | 区分没碰到球与碰到后没留住；不替代成功率 |
| 接触前像素定位误差↓ | 保留中位数与P95，覆盖所有有效查询，失败回合也计入；缺失状态另报 |
| 接触前距离/速度误差↓ | 防止二维主峰准确，却因测距或运动估计失败。可用三维位置误差与速度误差分析图表达 |
| 有效跟踪覆盖率↑ | 明确是有状态、由新事件更新、还是仅预测传播；不能只凭状态时间戳新就认定观测可靠 |
| 生成/估计成本↓ | 墙钟计算和模拟观测时延分别报告。10ms设定延迟不等于真实系统10ms端到端处理 |

暂不把“固定预测器相对GT预测器的到达误差”当作实测接取位置真值。若加入拦截指标，使用实际物理过线或接触事件定义参考；未过线、未接触的情况另外处理，不能只在模型判为可达的查询上统计后声称整体表现。

当前一条逆光失败是初始化准确却一直判静止。这应计入运动捕获失败，而不是从定位误差表中删去。建议失败分为：未建立运动跟踪、出画/遮挡后丢失、位置/速度错误导致错过、真实接触后掉落。类别根据日志和录像判定，不能凭最终失败倒推唯一原因。

本批已有一个值得直接展示的区分：普通组6/6发生过真实手部接触，但仅3/6完整成功；高速组5/6接触、3/6成功；逆光组2/6接触且这两条都成功。由此可见不同条件的主要失败环节并不相同，不能只用“定位不好”统称全部失败。接触数量来自全部回合记录，具体原因还需逐条日志佐证。

## 六、任务效用、训练数据效用和事件优势分别需要什么

**当前任务效用。** 固定原策略是一种有价值的控制变量：更换输入生成器，观察是否改变同一真实物理任务的结果。经典事件感知前端也能做这个实验，不必为追求“学习式”重训整个Catch It!。

还应补一个很小但关键的消融：保留同一首帧RGB-D与原策略，之后停止使用新事件、仅让原估计器预测。它用于检验接取收益是否确实来自后续事件更新，而非首帧初始化和来球先验。持握后不再持续观察并不自动否定完整接取，但本轮有成功回合在接触后状态缺失、依靠已有位置目标完成保持，报告应如实说明，不能称全程都有新事件闭环。

**合成训练数据效用。** 如果论文要写Ours数据比V2E数据更适合训练机器人感知，需要另做相同网络结构、标签、样本量、训练预算与模型选择规则的配对训练，之后在独立于各自训练来源的共同评价条件下测感知与闭环。最有力的共同来源是真实事件；替代的合成来源需要明确假设并检查结论对评价来源是否敏感。当前固定手工估计器与原策略实验不支持训练数据优越性的结论。Vid2E、v2e与ESIM的下游学习实验可作为设计先例。[Vid2E](https://arxiv.org/abs/1912.03095)、[v2e](https://arxiv.org/html/2006.07722v2)、[ESIM](https://proceedings.mlr.press/v87/rebecq18a/rebecq18a.pdf)

**事件优于帧输入。** 若论文要强调高速或逆光下事件比RGB更适合接球，还需要实际图像感知对照，同一任务与初始条件，图像方法按合理曝光、帧率、处理预算工作。不能从事件方法自己成功就推出优于RGB。帧基线只用于支撑这项结论；生成器之间的比较仍是主线。

真机接取会加强外部说服力，但作为整篇仿真器论文的一个闭环模块，我不认为必须复刻整台移动机械臂的真机实验才能使用这个任务。若论文其他模块提供独立的真实事件迁移证据，可以共同支撑仿真器价值；本会话不把那些尚未核实的结果计入本轮结论。

## 七、最小且直接的补实验顺序

1. 完成交付当前全部录像和逐查询误差，形成可复查的18条事件＋18条参考记录，保留所有失败。
2. 在开发数据上处理“释放后仍判静止”和近手阶段距离/速度估计问题，再次固定估计器。不是把目标设为必须超过某个成功率，而是避免当前已知前端故障主导全部比较。
3. 先用固定任务完成Ours/V2E配对闭环，同时补首帧初始化后不再接入新事件的消融，确认结果具有可解释差异，再接入其余既定方法。不能只在对Ours有利的子集上比较。
4. 预先保存正式新seed清单、条件和主指标，运行足够规模的三条件对照。报告逐seed配对和不确定性，不以“多跑到显著”为停止规则。
5. 补一张机制分析图：速度或逆光强度变化 → 感知误差/有效覆盖 → 完整接取成功率，同时给同条件状态参考，展示感知损失与机械能力的区别。

7°机位可继续保持为所有方法共享的安装参数。若不把相机优化作为论文贡献，就不需要展开大规模角度搜索；一份安装几何说明和测试前固定记录已足够交代其选择。[相机布置与接球分析论文](https://faculty.cc.gatech.edu/~hic/hic-papers/icra2007smith.pdf)

**本轮补充核查发现，7°并未显示更高的球心画内覆盖。** 在实际7°回合的归档飞行轨迹上，实际7°的球心画内比例为85.7%–100%；只把同一机器人/球轨迹重新投影到0°，比例为91.2%–100%，18条均不低于7°。这仅是几何投影，不是0°闭环或遮挡实验，不能据此认定0°接取一定更好；但足以否定“当前测试已经证明7°扩大了有效覆盖”的表述。如果论文要解释机位收益，应补真正的同seed角度对照；若不主张收益，7°作为既定共同安装即可。现有固定协议和数据不应因这项事后分析被重新筛选。

## 八、推荐论文图表

当前物体尺寸、外观和背景比较单一，新seed泛化还不等于对任意物体或复杂场景泛化。若还有余力，优先保留已知尺寸球体，补不同表面纹理或背景干扰；是否扩展形状取决于论文是否主张形状泛化，不应为此仓促更换整个估计器。

- 主demo：同一新来球下，方法间实际事件输入、估计轨迹和机器人接取的同步对比；另附全量成功/失败汇总。
- 主表：方法×普通/高速/逆光的完整接取成功率及区间，附真值状态参考，不把参考混进生成器排行。
- 分析图：像素/距离/速度误差及有效跟踪覆盖与接取成败的联系；按seed汇总，防止长回合因查询多而获得更高权重。
- 成本图或补充表：固定硬件下生成成本与任务效用的关系，明确模拟时间和墙钟时间。

当前最准确的论文表述是：“在固定机载相机和原有全身接取策略下，合成事件能够在新来球上驱动物理接取；我们进一步通过方法对照、压力条件和成对测试评估其效用。”其中后半句的正式方法对照尚待补齐，不能先写成已完成。
