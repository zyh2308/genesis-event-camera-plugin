这项核对在同一已记录的机器人状态上，按原代码定义计算目标相对位置及相邻控制时刻位置差；只运行 MuJoCo 前向运动学，没有推进物理、渲染或训练。真值仅用于离线核对。统计排除了最早两次查询、释放切换附近和末次碰撞控制步；详见 JSON 和归档脚本。

参考既有单目接球方法的连续轨迹拟合也做了 CPU 缓存验证，当前实现没有改善位置误差，所以没有作为新修复部署。论文是技术依据，不能替代本任务中的效果验证。参考：https://uav.hkust.edu.hk/wordpress/wp-content/uploads/2016/09/iser2016kunyue.pdf 。本试验在论文的观测射线/轨迹估计思路上加入名义线性阻尼，不是该论文的完整复现。
