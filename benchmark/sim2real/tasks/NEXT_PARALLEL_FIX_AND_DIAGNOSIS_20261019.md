## L1 重建：修复已确认的问题，尽快启动可信的新版本

两组 seed 0 已经完成 200 epoch / 12000 updates，但 TC 损失的采样坐标不一致：上游网格使用 align_corners=True 对应的归一化公式，两处 grid_sample 却使用默认 False。研究侧在实际环境复现了零光流仍使图像扭曲的问题。这轮权重和指标保留为历史记录，不能按正确 TC 协议验收。

1. 在 benchmark 的明确兼容层修复两处 TC 采样约定，保留上游版本和修复差异；不修改 frozen core。复用已补算的精确 10 ms 标签及原数据 split，无需因此重做物理 bank。
2. 开训门禁必须覆盖：零流恒等、已知平移、子像素位移、非方形尺寸、位移符号与有效边界，以及真实模型中 TC 的有效反传。检查预期数值与结果，不能只凭 exit 0、调用次数或有限梯度判定正确。同步检查增强与循环状态、保存恢复后的下一批次。
3. 门禁通过后，沿用既定模型、损失权重、训练预算与合成验证选点规则，从双方相同、已登记的随机初始化启动新版本 seed 0 配对训练。不要将旧权重续训作为修复后的正式对照。无需为例行启动再次等研究批准。
4. 两组各完成至少 20 次 optimizer 更新并验证 checkpoint 恢复后，及时交付证据，后台继续既定预算；暂不扩展其他 seeds。
5. 并行整理真实重建测试协议，明确 HQF 与原定 HS-ERGB 各自准备程度、对齐与评分方式。未经研究确认不要更换最终数据集角色，真实评分继续关闭。

## L2 光流：先用短诊断找准下一步，避免直接再跑一轮长训

已完成的 45 epoch / 8910 updates 配对训练及 synthetic-best 全部保留。全图多数预测接近零不能单独判定失败；最终选定权重在固定小样本共同事件活跃区已有改善，也不能据此声称真实域优势。当前原因尚未确定。

1. 对固定 synthetic-best 和同一组合成验证窗口做输入诊断：正常事件、全零事件、破坏时间顺序的事件。明确扰动发生在 raw events 还是时间表示上，确认确实改变模型输入；时间扰动尽量保留空间支持与总计数。所有版本使用从正常输入冻结的同一评价掩码，不能因置零而让有效像素消失。报告输出变化、误差与零流基线，说明其局限；不能仅凭模型对扰动敏感就认定它学会了正确运动。
2. 做一个有明确小预算的合成 GT 监督诊断，继续使用 STE-FlowNet。先检查小训练子集能否拟合，再观察独立合成 rollout；双方保持同初始化、采样和预算。采用成熟的多尺度光流监督及有效区约定，不发明新损失。该诊断作为独立版本保存，不覆盖当前无 GT 优化的正式协议，不做真实评分，不直接扩成正式长训。共享合成 GT 可用于这项诊断，推理输入仍只能是事件。
3. 汇总两项证据，区分输入信息不足、训练目标难以学到运动、数据覆盖不足，以及仍待排查的接口问题。若证据不足，明确写不足，不强行归因。先提交结论及一个推荐行动，不同时展开多个模型或大规模超参搜索。
4. 可并行制作小规模新版共享场景 pilot，增加纹理、场景、运动幅度与前景尺寸的覆盖，包含静止、低速和较快运动。训练/验证按独立物理 rollout 划分；每个场景先固定，再让两生成器共享轨迹与标签。不能按某一生成器事件数量挑样本，也不能调整传感器阈值来抬高指标。用合成统计验证它是否提供更有用的运动支持，记录成本，再提正式扩容方案；此阶段不直接启动另一轮完整光流训练。
5. 同时修复 MVSEC 评价器 checkpoint_index schema 错误，补上完整合成 artifact→manifest→权重绑定→评分入口检查。完善实际文件、哈希、时间窗、裁剪、公共掩码、空窗口、Outlier 和汇总定义。论文与 legacy code 裁剪差异须明确提交选择建议。保持真实评分关闭；不得用真实分数决定以上诊断或下一训练版本。
