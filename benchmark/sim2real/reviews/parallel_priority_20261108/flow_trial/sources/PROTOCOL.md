# 光流：只改变共享训练窗口采样的配对短训

本轮是单 seed 0 的合成开发诊断，不改仿真器、噪声、事件表示、模型、光度/平滑损失、有效区或正式结果。不给 GT flow 增加优化监督，不读取新的 MVSEC 分数。

## 诊断支持与局限

四层训练样本各 396 窗。静相机独立物体层约 97.1% 有效像素运动 <0.1 px/30ms，事件共同支持约 0.276%；其余三层平均运动约 1.27/1.33/1.55 px。因此不能说整个训练 bank 都缺少运动；这里只测试减少该低运动层曝光的局部假设。

光度输出梯度远大于已乘10的 smooth（后者约1.6%），不支持盲目降低 smooth。无效几何区占光度梯度能量约28–38%，且全有效区 GT 光度 oracle 未优于零流，表明目标仍有局限。本轮采样试验不能代替对光度假设的诊断，也不承诺有效。

## 预登记设计

- 两生成器各从**完整45轮 / 8910更新的 last.pt**固定分支，保持原完整 Adam、scheduler 和 RNG。它们是已完成权重，不通过原正式 resume 接口续跑；新脚本显式创建独立诊断 fork，旧 last、synthetic_best 及 MVSEC 矩阵均只读。
- Control：原 sampler 的下一 epoch45/46，原 `default_rng(seed + 1000003*epoch)`、batch8、相同增强 `SeedSequence([seed,epoch,batch,micro])`。
- Candidate：最终1600样本中四层计数为 `[480,160,480,480]`，低运动静相机独立物体层为10%，其余各30%。保留 Control 的全部非该层位置，只从该层位置随机保留160个，其余位置用另三层的均匀样本补足各480。约85%原样本/增强位置不变。替换只依赖已有物理层身份，不用事件生成器输出或验证指标决定概率。
- 两方法每个臂使用完全相同的物理索引和增强重放。不同臂样本有意不同；相同生成器两臂的初始模型、Adam、scheduler、RNG相同。不同生成器的已学习 Adam 数值自然不同，但超参数与起始更新数相同。
- 每臂额外200更新，共800主更新；smoke各臂1更新共4次，独立丢弃。恢复实际 LR 必须有限、正且同臂/两生成器一致；继续原 scheduler，不设新的 LR、不重置 Adam。
- 原 photo + 10*smooth、reference correlation、256联合变换及 FP32 / TF32-off 均复用冻结训练源码。GT只用于现成物理采样层、合成验证与标签配对哈希，不进入模型或 optimizer loss。

## 验证与解释边界

训练前和200步后，固定原 8 条验证 rollout、每条全部66窗，完整528窗。先窗平均、再rollout等权；同时保留逐stratum、共同事件活跃区和运动bins，空支持记录None，不伪造零。

开发质量检查（两个生成器分别满足才记为候选方向通过）：总体EPE和共同活跃区EPE均低于同期Control；四个stratum各自EPE恶化不得超过 `5%×Control`。所有loss和70组梯度有限、非零，Adam计数正确。静相机类必须单独报告，不以总体改善掩盖其退步。

200步检查点为唯一终点，不根据合成/真实结果挑步骤。即便开发检查通过，也不自动启动长训或真实测试；只有一个seed，不能作生成器最终排名或显著性结论。原权重文件训练前后SHA核对，所有输出新建，失败保留。
