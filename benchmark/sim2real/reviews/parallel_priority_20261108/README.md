## 光流：先诊断，再仅改变采样

实际合成诊断覆盖训练1584窗、验证528窗的bank统计，并对两组固定合成最佳权重各测32个验证窗及同一8样本梯度批次。解耦输出流场上，已乘10的smooth梯度范数仅为photo的约1.6%，不支持直接指控全网络过平滑。最细尺度约28%–38%的光度梯度能量位于几何/可见性无效区；该区域不能等同纯遮挡。

训练bank并非整体缺运动：三个相机/组合运动层平均位移约1.27–1.55px/30ms。静相机独立物体层则约97.1%的有效像素低于0.1px，故只测试减少该层曝光的假设，不改模型、损失或有效区。

新试验从两组已完成8910更新的 `last.pt` 做独立诊断分支，不动原正式权重或正在测试的synthetic_best。Control复刻原下一epoch采样；候选把低运动层从约25%降为10%，其余三层各30%，约85%的样本位置与增强保留。两生成器同臂共享物理索引及标签/增强，GT不加入优化监督。四臂实际恢复LR均为0.0001372，Adam/scheduler/RNG核验和一更新smoke通过；正式短训前的完整528窗分数必须与原8910步记录在1e-5内一致。

每臂追加200步，总800主更新；固定最后一步，完整8×66验证并报告各物理层、共同活跃区及运动bins。总体和活跃区均须改善，各层退步不得超过预设容差；单seed开发检查通过也不自动升级长训或真实测试。
