# 仿真器效率优化：执行交接

目标：降低 EventGenesis 生成成本，保留当前已验收的空间定位、时序和传感器语义。当前三线论文训练继续使用冻结核心 `62da4f35ce3c5c96f04268bd1687a27657af9238`，不重采、不重启、不混入候选输出。

先读同目录 `RESEARCH_REPORT.md` 及证据。已确认当前实际公开插件会因 300 Hz 低通和 `sensor_eps_target=0.05`，将五个检查区间的每个 10 ms 拆为 377 步；其余采样约束在这五例为 3–17。还存在中间帧 GPU→CPU→GPU、Python 标量同步、覆盖深度层循环和重复事件整理。没有完成动态分段耗时剖析，不能把静态发现直接当作耗时占比。

在独立候选 worktree、私有输出和环境扩展目录推进，工程细节自行解决。先做完整语义下的执行等价优化：

1. **固定代表输入并分段测量。** 使用既有合成训练缓存，涵盖相机/物体运动、纹理与遮挡。分开测数据读取、几何、覆盖、传输、DVS、排序、写盘；记录每区间采样数及约束来源。只在实时确认空闲并完成资源登记的卡上做有时限的短检，不干扰 g1/g3 当前训练，不在共享环境安装包。
2. **优先打通张量驻留。** 保留全部现有采样时刻、FP64 几何/传感器精度和随机过程，减少中间帧/诊断回 CPU。unknown、hold、surface 与 0.995 支持规则必须保留。现有 `DvsBatchEmulator` 不支持正式低通、噪声、不应期配置，不能直接替代。
3. **融合状态推进及事件写出。** 借鉴 OpenEB 与 Vid2E 的像素并行、时间顺序和计数/前缀和/紧凑写出。两遍处理不能重复推进状态或 RNG。缓冲溢出必须显式处理，不能截断事件。先保证逐位或预先约定的数值等价，再测实际整体收益。
4. **有证据后再优化几何采样频率。** 另建候选，让几何与传感器积分独立调度。不能通过关闭滤波、放宽 epsilon、缩小分辨率或减少噪声来称等价提速。多时间尺度属于算法近似变化，需要质量—速度消融和冻结版回归。

主要学习入口：ESIM 自适应采样；Vid2E GPU 两阶段事件输出；OpenEB 常驻传感器状态和直接事件体素；EsaacSim post-render GPU 接入。只借鉴适用部分，不能复制其单活跃像素单事件的演示简化。可在后续研究滤波仿射扫描，事件阈值/复位/不应期仍按像素的时间顺序处理。

必要验收：端点、support/unknown、遮挡、事件数量/地址/极性/时间及状态终值；低通/噪声/泄漏/不应期；固定 seed 和分块/恢复；固定模型定位回归；静止与高事件密度；溢出无丢失。真实测试集不参与优化、调参或选择版本。仿真生成可使用的物理状态不进入下游模型的特权输入。

交付按阶段归档：

- 先给冻结版逐段成本与采样分布，注明同步、预热、硬件、输入哈希和 worker 布局。
- 再给一个完整语义的等价候选、失败记录、事件/状态差异和端到端速度；没有收益就保留证据并停止该方向，不因局部 kernel 快就部署。
- 最后再评估多时间尺度候选的质量—速度折中。候选代码、证据、配置与报告放共享仓库，提供可复核的单一入口。

只有出现方向性问题、传感器语义必须变化、定位回归或无法安全取得短检资源时向研究侧汇报。不要等待正式长训练完成才做接口和数值检查；也不要为了这条优化线暂停正在运行的三项实验。
