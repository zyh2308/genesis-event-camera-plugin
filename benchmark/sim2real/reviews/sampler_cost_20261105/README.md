# EventGenesis 自适应采样计算优化核验报告

新版相对上一 GPU 版本的完整管线加速比为 **1.242×**（五类片段比值的几何平均）。 相对 V2E 原生自动采样，新版耗时仍为 **28.042×**，不能声称总体快于 V2E。

本轮保留全部传感器时刻、数值精度、噪声随机调用、覆盖与遮挡规则；优化重复选行、未使用的混合计算和仅用于循环上界的直方图。结果属于隔离候选验收；没有修改训练、覆盖冻结版本或自动替换生产仿真器。

## 计时协议与主要结果

同一组固定登记的五类合成片段、同源物理/显示输入哈希；每片段20个物理区间、每方法3次计时重复。共享服务器 g1 的 GPU2（`GPU-a02affe0-7598-579e-ca39-f551f35ad6e9`），Torch 2个CPU线程、interop 1线程，TF32关闭。重复计时不是训练seed，也不是置信区间。

主指标从每片段初始化开始，包含 setup 和生成、各自传感器首帧初始化，终点为按时间排序的CPU原始事件。预训练SSM网络与私有CUDA算子已预热；双方均不包含 Genesis 物理渲染、输入磁盘读取和结果序列化。

V2E使用官方SuperSloMo原生自动插帧、最低倍率2，传感器沿用预先登记的300Hz带宽和全噪声配置；这不等同于V2E所有参数均为默认值。双方使用各自原生自动采样，没有强制V2E采用377倍插帧。

## 为什么仍保留377步

当前物理间隔Δt=10毫秒、带宽f_c=300Hz，τ=1/(2πf_c)=0.530516毫秒。冻结采样器的一项下界为 `N_sensor = ceil((Δt/τ)/ε_target)`；最终仍与其他运动、几何及辐照度约束取最大值。从实际传感器初始化配置读取 ε_target=0.05，该项给出 377 步，已与每次实际采样记录核对。

该约束限制离散低通更新系数，不是最终事件时刻误差的证明，也不是相机标定精度。直接减少子步会改变RNG调用序列、漏电抖动累计方差及shot噪声与不应期的联合分布；即使噪声率参数相同，也不能认为噪声概率分布不变。本轮因此没有把377硬改为更小值。
