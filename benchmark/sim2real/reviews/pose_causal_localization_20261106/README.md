## 当前判断

1. 存在明确的合成域学习/泛化问题，不能把失败主要归于Sim-to-Real域差。
2. 纯中心选点、纯角点编号或PnP求解失败，都不足以解释主误差。
3. 已见样本低误差与独立轨迹高误差，以及此前小集追加训练后验证变差，支持数据覆盖/过拟合方向；这仍需场景对照而非仅凭相关性宣布唯一根因。
4. 以关键点EPE选checkpoint可能与完整机器人位姿目标错位，应在新候选版本使用合成完整ADD-S检验。原Stage9协议和权重不改。
