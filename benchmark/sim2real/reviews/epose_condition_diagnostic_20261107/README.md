# E-POSE 木块位姿 · 合成到真实的误差分解

## 结果

EventGenesis 训练的模型在真实中、低光下会系统性低估距离。低光的真实距离平均约 50.4 cm，它平均估近 25.3 cm，而 V2E 平均估远 1.6 cm。将真实距离限制在 45–55 cm 后，EventGenesis 的偏差仍从正常光的 +5.2 cm 变为中光的 −16.8 cm 和低光的 −26.8 cm。四种同时覆盖三档光照的名义运动条件也复现了这个方向。

| 光照 | 主测试序列 | 深度有符号偏差 EG / V2E (cm) | 深度 MAE EG / V2E (cm) | 完整成功率 EG / V2E (%) | 中心误差 EG / V2E (px) | 纯旋转 ADD-S 误差 EG / V2E (cm) |
|---|---:|---:|---:|---:|---:|---:|
| 正常光 | 4 | +11.16 / +6.99 | 15.14 / 11.23 | 22.63 / 23.46 | 60.54 / 54.72 | 1.70 / 1.76 |
| 中光 | 6 | −15.19 / +1.12 | 17.59 / 12.62 | 0.86 / 5.62 | 83.65 / 71.84 | 2.48 / 2.15 |
| 低光 | 6 | −25.30 / +1.63 | 25.30 / 14.23 | 0.00 / 1.79 | 74.04 / 69.43 | 2.74 / 2.18 |

分解尺度公式后，低光下 EventGenesis 的预测表观尺度是真值的约 1.68 倍，形状修正因子是真值的约 0.85 倍，两者合在一起令预测距离只剩约 0.51 倍。V2E 对应比值约为 1.02、1.03 和 1.01。这些比值按窗口、种子和序列的平均对数计算。低光窗口的事件数也普遍更高，不能用事件总数解释哪组更能看清物体边界。

将 EventGenesis 的预测分量逐个换成 V2E 的预测，在 1,024 个保留窗口上得到 +7.44 个百分点的 AUC 差，深度、中心、旋转分别贡献 +6.18、+1.07、+0.19 个百分点。深度 AUC 贡献的 95% 配对序列区间为 [2.84, 9.03]。对于严格阈值下的成功率，三项分别贡献 +1.38、+0.53、+0.56 个百分点，其中深度区间 [−0.34, 3.23] 跨零。深度是连续质量差距的主要来源，跨过成功阈值还取决于其他分量。

使用真值单独纠正 EventGenesis 深度时，抽样成功率从 6.02% 提高到 15.04%。单独纠正中心和旋转分别为 8.76% 和 6.84%。低光只纠正深度时从 0 升到 4.43%，单独纠正其他两项仍为 0。真值替换仅用于诊断，不是可部署结果。

名义含旋转和平移两组均存在真实差距，成功率分别为 2.16% / 4.92% 和 8.95% / 11.54%。中光平移的 `t_05_ml` 和 `t_10_ml` 差距最大一档，V2E 分别领先约 9.89 和 10.04 个百分点。正常光下也有序列差异，`r_10_gl` 是 V2E 更好，`t_10_gl` 则 EventGenesis 更好。速度和光照不能从这些序列单独识别为因果效应。

合成场景代码随机化了姿态、距离和运动，但环境照明固定。合成优胜说明模型能利用当前合成域中的尺度信息，真实结果显示这套尺度估计在照明变化下失准。诊断已定位到预测环节，具体的传感器响应、背景事件、材质和光照贡献仍要通过共享物理轨迹的控制实验区分。

## 数据与指标

保留原 E-POSE 木块主结果的 16 条序列、16,839 个窗口。按序列等权，三组随机种子配对。全量距离诊断取六组均能对齐的同一批窗口，完整成功率沿用原评估的完整分母。另两条已见序列单列。冻结模型在每条序列按原始次序等间隔抽取 64 个窗口，使用 CPU 重新计算中心、尺度和旋转。重算结果对齐已归档的 GPU 深度及完整 ADD-S。没有训练、选权重或修改正式 E-POSE 结果。

深度误差为预测距离减真值，负数表示估近。定位是物体 CAD 中心在原始理想投影坐标系中的二维误差，另算使用正确深度时中心误差造成的实际横向偏移。旋转误差使用以真实 CAD 中心对齐后的全点 ADD-S，减少对称朝向的歧义。旋转替换以原标注线性部分的极分解旋转为参照，评分继续使用原生位姿矩阵变换的真值 CAD。

同窗口、同 seed 将三个预测分量在两模型之间穷举互换，取六种替换顺序的平均边际变化。三项贡献相加恰好等于抽样窗口上的分数差。单项真值替换另作诊断。两类诊断衡量输出层面的差距，生成器物理原因需要另做干预。

E-POSE 论文定义正常光 GL、中光 ML、低光 LL，标称照度约 830、170、18 lux。速度代码 01、05、10 分别为 0.1、0.5、1.0 m/s。`r` 为含旋转轨迹，`t` 为标称平移轨迹。本次核验的 `t_01_ml` 原生标签存在可观旋转变化，分组按数据集标签处理，涉及运动的结果作描述性统计。[E-POSE 论文](https://www.nature.com/articles/s41597-025-04536-5)

## 可验证的下一步

1. **先验证同一物体是否会因为照明而被估成不同大小。** 复用同一批 Genesis 物理轨迹、CAD、相机参数和标签，在正常、中、低三个光照档重渲染，覆盖近中远、平移和含旋转运动。两个生成器共享各档物理输入，做等量配对。合成训练和验证按整条物理轨迹切分，同轨迹的不同光照始终在同一侧。分别记录物体投影尺度对数偏差、深度偏差、中心误差和完整 ADD-S。
2. **用等预算的对照把数据覆盖和下游模型分开。** 首先只改合成光照覆盖，保留两生成器原有设置和下游配方。随后用同一扩展数据训练有无跨光照几何一致性约束的两组模型，约束同一姿态的尺度和深度在光照变换下保持一致。若第一组仍出现暗光尺度偏差，再用独立 DAVIS 标定数据确定传感器配置范围，单独检查低光响应、阈值和噪声。V2E 论文中的亮度相关带宽与噪声可作标定对照。[V2E 论文](https://openaccess.thecvf.com/content/CVPR2021W/EventVision/html/Hu_v2e_From_Video_Frames_to_Realistic_DVS_Events_CVPRW_2021_paper.html)
3. **先锁定成功条件，再进入真实测试。** 三个配对 seed 在独立合成轨迹上都应降低中低光深度 MAE，配对 95% 区间下界为正，正常光表现满足预先登记的容许范围。再用相同模型和预算做一次独立真实确认。已经查看的 E-POSE 木块序列用于诊断，新的主要真实结果需要独立采集的同物体序列，或预先锁定的其他 E-POSE 物体和匹配 CAD。现有结果按原协议保留。
