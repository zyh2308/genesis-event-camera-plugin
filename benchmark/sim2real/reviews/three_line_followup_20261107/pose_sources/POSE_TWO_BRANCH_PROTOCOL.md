# Independent localizer and depth under matched physical illumination

The preceding depth-only experiments retained a fixed final localizer to isolate depth. Their darkest mean center errors were approximately 30.2px (EventGenesis) and 15.6px (V2E); depth improvement alone does not address this observed limitation. This follow-up uses two independent copies of the existing CenterScale network. It is a downstream training change, never a simulator/noise/occlusion change.

1. Keep the full-coverage depth learner exactly unchanged (fit-function AST identical).
2. Train a separate localization copy from the same per-method/seed normal parent, using only the existing Gaussian center cross-entropy and normalized-center SmoothL1 terms. Freeze its unused size head. Normal teacher retention weight2, matched-normal-view consistency weight2; KL over the existing 16×16 center probabilities plus center SmoothL1. These reuse the existing learning rate, supervision and common coefficient, with no real-data tuning.
3. Preserve all three matched arms: normal auxiliary control, relit supervised, relit paired consistency. Both methods/seeds0/1/2 receive the same budget: 288 depth updates AND 288 localization updates per arm. Final epoch weights are fixed. All source, data, original normal parents and rotations remain bound by SHA. The teacher for relit inputs sees the same physical window and affine geometry at normal radiance.
4. Report depth-only predictions with the frozen parent localizer/rotation, translation-only fusion with learned centers but frozen original rotations, and the pre-specified final full-pose pipeline using learned centers and depth-estimated box size for the frozen rotation head's crop/ray frame. All use the SAME depth weights. These ablations separate the center translation effect from the predicted-crop effect. Never use a GT crop or choose a variant using real scores.
5. Preserve the original 30 illumination checks and the eight earlier original-PnP/fixed-median confirmation comparisons on their full original 96-trajectory candidate-window sets. The original four-window subset for illumination checks is retained separately. All checks must pass for the pre-specified paired-consistency fused model before E-POSE. Otherwise save failure evidence and stop scoring; no seed exclusion or threshold relaxation.

The E-POSE evaluator binds both trained localizer and depth weights independently for each real arm. Rotation-head weights remain frozen; its input crop and ray frame use the current predicted center and depth-estimated size, following the normal predicted-pose pipeline. The original scale weights are bound only for training lineage and synthetic ablations, not required as an extra real inference model. Inputs are whole-frame events/public K only. It scores all20,916 registered samples for matched clean-control and paired-consistency bundles, all methods/seeds in this diagnostic. This is previously inspected woodblock development data, not a blind final holdout. The rest of the paper's simulator baselines require the same adopted downstream recipe before inclusion in a comparison table.

Preparation stays on its existing run. The prior CPU-only waiting launch is replaced before it acquires a GPU or starts training; its source and cancellation receipt remain. The new wait does not reserve a GPU. After source/data/overlap checks, use the existing atomic lease and automatic release. No reconstruction or flow job is stopped or changed.
