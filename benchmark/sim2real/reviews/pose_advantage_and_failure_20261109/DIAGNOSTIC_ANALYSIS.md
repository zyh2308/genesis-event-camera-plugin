# 位姿：已有优势、暗光失败位置与下一步

本轮最重要的进展是：已经把“暗光下位姿不好”缩小到可检验的具体问题。一个困难场景中，EventGenesis 训练出的中心网会把地面或干扰物当成目标；中心一旦偏移，还会把后面的旋转裁剪带偏。与此同时，深度误差是另一项独立限制。现在有证据支持分支定位，仍没有证据声称已经修好或全面超过 V2E。

## 当前能报告的模型结果

以下是固定 RAW C1 模型、两生成器、三 seed、四条既有合成验证轨迹的均值。每光照为相同64个物理窗口；192是64窗×3seed的预测次数，不是192个独立物理样本。

| 光照 | 中心误差 EG / V2E（px） | 深度 MAE EG / V2E（cm） | 完整位姿成功率 EG / V2E（%） |
|---|---:|---:|---:|
| 正常 | 8.21 / 14.61 | 4.23 / 4.69 | 35.94 / 29.69 |
| 半亮 | 9.99 / 15.78 | 3.59 / 3.64 | 37.50 / 33.33 |
| 最暗 | 29.28 / 15.75 | 6.38 / 5.87 | 20.31 / 31.25 |

正常、半亮存在条件优势；最暗仍明显落后。这四条轨迹已经用于多次诊断和候选开发，不能把这些优势写成独立确认或真实域泛化结论。三种光照使用同组固定模型，没有按光照拼接不同候选的最好结果。

## 暗光究竟错在哪里

已检查全部1,152次原模型预测，同时核对原始16×16概率图、真实物体可见区域和窗口起止区域。

- EventGenesis 最暗条件下，47/192次峰值点在端点物体外；其中19次仍位于与物体有重叠的粗格，不能据此说识别错物体。另28/192次的峰值格在端点及起止并集都没有目标支持，是真正离开目标区域的错误。V2E 最暗的相应数量为0/192；它也有25次峰值点在物体外，但这些粗格仍与目标重叠。
- 这28次全部集中于 `validation_031`，三个seed分别12、7、9次。表面核对显示23次落到seg0，5次落到seg5；根会话已进一步核对其为地面与干扰物。**不能只凭分割ID自行推断物体身份。**该场景平均中心误差69.76px；其他三条分别11.11、29.65、6.59px。`validation_063` 仍有29.65px误差，却没有上述真正离开目标格的问题，因此“识别错对象”不是全部错误的唯一解释。
- 同批物体轮廓未接触画面边界，GT anchor均可见且处于原读出可表达范围。物体anchor窗内平均移动约2.17px，最近16格点的离散参照误差约7.92px，均不足以单独解释031的近70px偏移。这个离散参照仅用于峰值，**不是连续softargmax的精度下限**。
- 最暗时EventGenesis目标区域仍平均有约906个事件、占用率19.7%；V2E约564个、12.1%。这排除了“总体几乎没有目标事件”的简单说法，但事件总数不等于有效定位信息，也不能据此证明事件质量领先。区域内事件可能含背景穿越或其他来源，GT区域统计只用于事后诊断。

因此，当前最具体的解释是：困难暗光场景中的目标选择/特征泛化出现了问题，且另一些窗口仍存在目标内部anchor偏移或概率分布误差。不能把它统称为时间错位、量化误差或事件不足，也不能据相关统计认定唯一根因。

## 为什么中心错一点，完整位姿会错很多

中心不只决定“物体在画面哪里”。它还决定相机平移射线，以及送入固定旋转网的裁剪位置。深度来自独立分支，决定物体距离。下表通过旧缓存预测做CPU几何替换，拆开这些路径。

**所有GT替换均为不可部署的诊断条件，不是新模型成绩；不能在实际推理中读取GT中心或深度。**裁剪旋转使用此前已经保存的GT中心crop输出，本轮没有重新推理、裁图或训练，预测crop尺寸保持原值。

| 最暗条件的完整位姿成功率（%） | EventGenesis | V2E |
|---|---:|---:|
| 原始预测 | 20.31 | 31.25 |
| 仅替换GT中心，R仍固定原预测 | 25.52 | 34.38 |
| 仅替换GT深度，中心与R保持原预测 | 33.85 | 45.83 |
| GT中心＋GT深度，R仍固定原预测 | 51.56 | 64.06 |
| GT中心并采用已存GT中心crop的R，深度仍预测 | 41.15 | 39.58 |
| 上一行再替换GT深度 | 85.42 | 80.73 |

对EventGenesis，GT中心只修正平移时从20.31%到25.52%；让同一个GT中心同时对应正确位置的旋转裁剪，则到41.15%。这说明定位错误确实会经裁剪放大到旋转，并非旋转网在暗光下完全不会工作。进一步给GT深度后达到85.42%，又说明深度仍是重要瓶颈。

这些是**条件性路径干预**：两条路径和其他预测因素相互依赖，不能把百分比差当成可以相加的“各错误贡献率”，不能声称已唯一识别网络内部原因。普通旋转角误差也受物体对称性影响，核心判断应沿用ADD-S及完整位姿成功率。

正常、半亮的相同诊断也显示裁剪路径影响：EventGenesis在GT中心、预测深度时，固定R成功率均为43.23%；改用已存GT中心crop的R后分别为57.81%、59.38%。因此后续必须评价重新裁剪后的完整位姿，不能只优化中心像素误差。

## 接下来怎样推进、怎样避免夸大

错峰证据为“训练期目标mask辅助监督”的配对短检提供了具体依据：帮助中心分支学会区分目标和地面/干扰物，推理仍使用原事件输入及原中心读出。它仍是待验证方案，不能保证修复深度或真实泛化。对照必须保持两生成器的共享物理数据、原初始化、样本/增强tape和训练预算；不能把GT mask喂给推理，也不能按验证场景有利与否删窗。原30＋8稳定性门槛不放宽；未通过就保留RAW C1，不采用新候选，不开启新的真实评分。

另一方面，32条新轨迹的独立合成确认已完成**物理数据生成**。当前本地证据尚没有两生成器事件准备与完整评价的最终收据，不能称优势已经复验。正常、半亮是预登记的两个primary条件；最暗必须同时完整报告。评价将冻结既有RAW C1，不因新结果改模型，按轨迹聚合、三seed配对、32轨迹成组bootstrap处理两个primary比较。即便成功，也只能确认同一生成分布下的独立合成条件优势，不能替代真实E-POSE泛化结果。

历史E-POSE各序列已经评分并用于后续误差分析，其原“保留”角色属于历史；新的优化不能继续声称这些序列仍未见。最终论文的真实泛化主张必须如实说明数据暴露历史，不能用本轮GT诊断或32条合成确认替代。
