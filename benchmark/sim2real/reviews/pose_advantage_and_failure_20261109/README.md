## 2. 暗光峰偏到了哪里

原RAW C1全部1152次预测、384个唯一事件支持窗口已检查。最暗64窗×三seed中，EG有28次峰值格在端点与起止并集内均无目标支持，全部来自既有`validation_031`；三个seed分别12、7、9次。事后原始表面ID核对：23次落在地面、5次落在干扰盒。V2E同一批窗口相应为0/192。

另有19次EG峰值点虽在目标外，其16格仍与物体重叠，不能把它们混算为错对象。192是模型预测次数，并非192条独立轨迹。渲染表面ID与区域内事件计数也不等于逐事件来源或噪声标签。

`031`的EG平均中心误差69.76px；最近硬网格参照约7.92px、窗口内物体运动约数px，均不足以解释。目标区域事件平均数量也并不比V2E少，因此“整体没有目标事件”不是合适解释。另一条`063`仍有29.65px中心误差，却没有上述真脱靶峰；错对象不是所有误差的唯一机制。

当前证据把问题缩小到困难暗光中的目标选择/特征泛化和目标内分布偏移，没有证明冻结事件生成器存在某个确定的噪声或时间规则错误。

## 3. 定位与深度如何影响完整位姿

中心既影响平移射线，也影响旋转网裁剪。下表使用缓存的预测与已存GT中心crop旋转，进行CPU几何诊断。本轮该项0前向、0更新；GT替换仅作不可部署的oracle，不是模型成绩，也不能把差值相加当作唯一因果贡献。

| 最暗条件的ADD-S成功率 | EG | V2E |
|---|---:|---:|
| 原始预测 | 20.31% | 31.25% |
| 仅GT中心，原R固定 | 25.52% | 34.38% |
| 仅GT深度，原中心/R固定 | 33.85% | 45.83% |
| GT中心＋GT深度，原R固定 | 51.56% | 64.06% |
| GT中心＋对应GT中心crop的R，仍预测深度 | 41.15% | 39.58% |
| 上一行再替换GT深度 | 85.42% | 80.73% |

只修中心的平移路径改善有限；正确位置的旋转裁剪会进一步改变结果，深度则仍独立限制完整位姿。因此平均中心误差下降，并不保证完整位姿成功率上升。模型使用预测尺寸的裁剪、ray-frame旋转和ADD-S对称性定义均沿原协议。

## 4. 已实际完成的针对性配对短训

借鉴[GDR-Net（CVPR 2021）](https://openaccess.thecvf.com/content/CVPR2021/html/Wang_GDR-Net_Geometry-Guided_Direct_Regression_Network_for_Monocular_6D_Object_Pose_CVPR_2021_paper.html)的显式物体几何辅助监督思路，在原中心主干增加训练期1×1可见mask辅助头，fractional class-balanced BCE系数1；类平衡损失参考[HED（ICCV 2015）](https://openaccess.thecvf.com/content_iccv_2015/papers/Xie_Holistically-Nested_Edge_Detection_ICCV_2015_paper.pdf)。这是适配实验，不是原论文模型或默认配方复现。

- 两生成器×三seed，从各自原C1训练的同一source-init重新出发，沿同一完整288步样本/增强tape，原中心监督、正常teacher、优化器及预算不变。每组288更新，共1728；前置smoke两组各1更新，另计2次。
