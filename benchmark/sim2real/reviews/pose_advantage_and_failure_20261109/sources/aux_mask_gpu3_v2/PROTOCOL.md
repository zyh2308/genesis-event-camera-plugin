# RAW C1 + auxiliary visible-mask center short trial

The registered trigger is a descriptive fixed-cohort diagnosis: EventGenesis has28/192 darkest-condition peaks with no endpoint/endpoint-union target support in the corresponding attention cell, all on validation_031; the three seeds contribute12/16,7/16,9/16. V2E has0/192 in this category. Native peak-point misses with fractional cell support are kept separate. This motivates one auxiliary supervision hypothesis; it does not establish a unique cause or promise a generator ranking.

The only new training component is a separately checkpointed Conv2d(64,1,1) head on student features. Original e188 C1 center supervision, normal RAW teacher weight2, source initialization, RAW normal1529 NPZ inputs/labels/order, RAW half/eighth3058 auxiliary windows, p(half)=.75, six epochs288updates, AdamW lr.00015/wd.01 and clipping5 are preserved. The original forward/global-expectation UV is unchanged. Size is frozen; independent C1 depth and original rotation weights are reused. Every evaluated pose actually uses its predicted center with the original RAW crop, ray frame, rotation head and native scorer.

Loss coefficient is fixed1. For each image, with fractional occupancy m, auxiliary loss is .5 sum[m softplus(-l)]/sum[m] + .5 sum[(1-m) softplus(l)]/sum[1-m], then batch mean; the normal/auxiliary views have equal .5 weighting. An absent class contributes zero without redistributing its .5 weight; all windows remain and positive/negative effective masses and empty-class counts are logged. This full-image adaptation is not claimed to be the default GDR-Net loss. There is no coefficient sweep.

Visible masks are TRAIN loss labels only, obtained via the frozen dynamic target-identity/21-frame count/depth-positivity checks. Endpointk+1 labels match the original (ts[k],ts[k+1]] pose endpoint; masks do not identify the physical source of every event during10ms. Native bool260x346 -> OpenCV LINEAR416 -> CPU AREA128 occupancy is transformed with exactly the image's original affine draw, then AREA16. Cloned NumPy RNG state provides the same transform without advancing the official RNG a second time. Head initialization uses an independent CPU fork_rng and never advances original CPU/CUDA sampling state. Original normal NPZ labels are retained despite their known float32 geometry rounding.

All six full288 sample/augmentation/label tapes must match the immutable original C1 logs before either smoke update. Original1529 RAW NPZ images must also equal their original fresh re-encoding after native CUDA AREA128. Shared physical mask128 hashes must agree across methods. Every actual update is checked against the original tape; the first native-only scalar terms must reproduce the original C1 update1 log within fixed2e-6+1e-6|oldloss| tolerance. The old model parameters and auxiliary parameters receive finite gradients; size and teacher receive none. This is an oracle for the retained native part, not a claim that the auxiliary update equals the original optimizer step.

Smoke: method EG/V2E seed0, one actual update each, followed by independently instantiated original model + separate auxiliary head + Adam state readback. Study requires the SHA-bound successful smoke, uses all three seeds and exactly6x288=1728 new center updates from original source-init. It does not continue the one-step smoke models. No interruption-resume equivalence is claimed; resume_supported=False. Failure preserves its new directory and requires a separate explicit recovery decision.

Immutable input lineage includes all used NPZ, physical H5, event NPY/manifests, relighting completion, source/model/control receipts and logs. Caches bind source and registered contract SHA; input bytes are checked on creation, study load, and completion. Existing files and controls are never overwritten.

Evaluation keeps clean384 and matched-normal64 separate, plus half64/eighth64. The original36 center-stage checks are retained, and12 additional matched-normal checks require center error and pose success not to worsen. Both groups are reported separately; neither replaces the original formal30+8, which are not retested/passed by this probe. The auxiliary head is evaluated only for posthoc mask metrics; its output is discarded from the pose path. No GT mask/crop/box/illumination enters model input or pose inference; no new real E-POSE scoring, no new long training, no changes to simulator core/noise/occlusion.
