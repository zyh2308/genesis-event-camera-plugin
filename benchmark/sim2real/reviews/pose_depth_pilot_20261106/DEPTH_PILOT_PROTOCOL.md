# 位姿独立深度分支短训

- 冻结每组原先按合成 EPE 选出的骨干。仅从原全帧事件输入提取最后一个卷积前的特征，组合全图池化与原模型选中的网格特征。用合成训练集统计做归一化，训练小型 MLP 预测 CAD 中心对数深度。
- EventGenesis 和 V2E 各跑配对 seed 0、1、2。同 seed 的新分支初始化、样本顺序、8 个 epoch 和超参数一致。使用最后一步，验证集不选轮次。每次推理同时输出原 EPnP、训练集固定中位深度和学习深度。两种替换均保持 EPnP 的旋转和物体中心视线。
- 验证覆盖全部 510 个窗口和 32 条独立轨迹，轨迹等权。ADD-S 使用完整 CAD、GT 到估计方向、严格小于 0.1D。无效几何计入成功率分母。深度 MAE 在原 EPnP 有效的共同窗口比较，分开记录候选无效数、AUC 和绝对误差中位数。
- 每个生成器的三个 seed 都必须在深度 MAE 和完整 ADD-S 成功率上超过两个对照。跨种子平均改善的 95% 配对轨迹 bootstrap 区间下界也必须大于零。合成门禁通过后才进入现有 E-POSE 木块协议。固定真实测试输入和标签，深度分支推理只读事件，验证标签只进入指标。
- g1 现有 GPU 5 队列，CPU 线程限制为 2。新建唯一运行目录，分别保留预检和正式证据。
