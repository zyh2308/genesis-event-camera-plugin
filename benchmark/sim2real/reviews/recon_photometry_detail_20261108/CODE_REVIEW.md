## v1 / v2 失败记录与 v3 的解释

按主代理提供的实际诊断，v1 的逐位梯度一致检查失败；v2 在预先指定的 `rtol=1e-5, atol=1e-7` 下，原生函数与自身重复运行也未达到逐张量 allclose。原生重复的最大绝对梯度差约 `3.1e-7–5.0e-7`、相对 L2 约 `4e-6–6e-6`；loss 一致。

这些数值来自主代理读取的服务器诊断，本审查未独立远程复算。v1/v2 失败产物必须保留，不能重标为通过。v3 没有继续放宽梯度容差，而是直接使用原生函数身份约束，独立检查辅助项公式及梯度；原生 CUDA 自重复数值差作为诊断保存。

v3 **不宣称 CUDA 反传或整段训练逐位确定性**。即使调用相同函数，CUDA 原子梯度累加仍可能产生微小差异；这不能单独证明接法改变，也不能作为省略样本配对和结果核验的理由。
