# 位姿独立合成确认

冻结旋转短训后的中心、尺度和旋转权重。以合成物理种子 `20261106017` 一次性生成 96 条新轨迹，物理分布和 20 个 10 ms 区间沿用 Stage 9。EventGenesis 与 V2E 使用同一批物理缓存，各自沿用原已冻结的事件生成器、参数、预处理与相机内参。只按合成标签判定投影中心是否在传感器内，两组共用有效窗口。

完整评分保持与原门槛一致。原模型、训练集固定中位深度和已冻结的新位姿分支，各使用三个配对种子。每个生成器、每个种子和两个对照都须在深度 MAE 和全 CAD ADD-S 成功率上提高，按新轨迹配对 bootstrap 的 95% 下界也须为正。原 32 条轨迹与新 96 条轨迹分开报告。只预检工程接口，固定完整作业结束后再查看新验证分数。真实 E-POSE 仅在确认通过后启用。

g1 GPU 5 的预检作业为 `118_pose_fresh_confirm_smoke_20261106`。它使用独立的两个工程预检轨迹。完整作业 `119_pose_fresh_confirm_paired_20261106` 的启动条件为预检完成且退出码为零。完整作业以 `--real-on-pass` 启动，只有新合成评分已写盘、门槛全部满足且权重与协议哈希匹配，才在同一作业内开启 E-POSE。E-POSE 主结果仍单列原协议的 `untouched_primary` 序列。
