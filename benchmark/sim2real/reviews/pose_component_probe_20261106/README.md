# 位姿成功率的误差分解 · 2026-11-06

物体沿相机视线的距离是当前最大的瓶颈。两组模型的距离中位绝对误差为 32.3–38.9 cm，而完整位姿的 ADD-S 成功门槛为 2.37 cm（CAD 直径的 10%）。该门槛是整体模型点距离，和单项深度误差的定义不同。

## 配对实验

g1 GPU 5，seed 0。每个生成器使用同一组 510 个合成窗口，32 条独立验证轨迹等权，完整木块 CAD 用于计算 ADD-S。保留原来按合成关键点 EPE 选出的权重，另报告第 30,000 步权重。重新推理得到的二维 EPE 与对应训练记录一致。下表各项为 ADD-S 成功率，深度误差为窗口级中位数。

| V2E | 30,000 | 61.98 | 32.3 | 1.95% | 0.00% | 2.93% | 3.32% | 35.35% | 49.61% |

纠正深度时保持物体 CAD 中心的预测视线及预测旋转。纠正视线时保持预测深度及预测旋转。纠正旋转时保持预测三维中心。几项纠正均使用合成真值隔离误差来源，收益会相互影响，不能相加。上一轮用全部真值二维点运行同一 EPnP，在这 510 个窗口上达到 100%。LM 是本轮实际测试的无真值推理改法，四组的成功率和 AUC 均下降。

两组原选权重的 AUC@0.1m 分别为 10.50% 和 4.70%，仅纠正深度后升至 67.44% 和 60.35%，趋势与阈值成功率一致。最终轮 EPE 更高，原始 ADD-S 成功率和 AUC 却都略升，表明单用 EPE 选模型会漏掉完整位姿的信息。修正整个三维中心后仍约半数失败，旋转与角点几何仍需改善。单 seed 的结果用于确定诊断优先级。

对照文档和源数据统计显示训练深度范围约 0.38–1.14 m，验证约 0.47–1.14 m。当前对照能定位深度估计环节，尚未区分事件表示、场景覆盖和网络设计各自造成的误差。本轮未读取真实测试数据。冻结权重、仿真器和正式评估协议保留原状。

## 学界对照和短训设计

- [AEE](https://doi.org/10.1109/lra.2025.3644151) 也在 E-POSE 上评估 synthetic-only 事件位姿模型。它用模型检测框定位物体，用密集姿态模板匹配旋转，再用表观尺度和焦距估计深度。论文分别报告完整 ADD-S 和用真值平移隔离出的旋转成绩，也观察到平移造成明显降幅。我们目前从全帧的单个网格单元回归八个角点，平移与旋转都交给同一个 EPnP 解算。AEE 的旋转成绩与我们的完整位姿成功率口径不同。
- [PoseCNN](https://arxiv.org/abs/1711.00199) 单独估计图像中心与物体距离。[GDR-Net](https://campar.in.tum.de/pub/wang2021gdrnet/wang2021gdrnet.pdf) 使用检测框归一化的平移表示，分开监督旋转、中心与深度。这两条 RGB 研究路线提供了可在纯事件输入下独立验证的几何设计。
- [PVNet](https://arxiv.org/abs/1812.11788) 用多个像素对关键点投票，并给 PnP 提供关键点不确定性。它针对的是单点回归在遮挡下不稳的问题，可用来改善纠正平移后仍然残留的误差。

下一步先在现有骨干上短训一个独立深度头。用合成训练标签监督对数深度，推理只用事件，保持原模型的旋转及视线预测，直接检验独立深度能带来多少完整位姿收益。以训练集深度中位数作常数对照，避免把固定场景的距离先验当作学到的能力。两生成器共享初始化、训练预算、场景和指标。先看完整合成验证的深度误差、ADD-S 和 AUC，按轨迹和距离分层，并在三个配对 seed 复核。若有稳定增益，再加入预测框的尺度和密集关键点，分别检验。确定最终方案后按冻结协议做真实评分。
