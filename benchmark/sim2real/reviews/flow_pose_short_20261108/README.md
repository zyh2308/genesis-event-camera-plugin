## Census为单项结构鲁棒性消融

借鉴作者实现的soft Census，用局部相对明暗结构替换绝对亮度Charbonnier，保留原四尺度pixel-SUM、smooth×10、原control采样、模型和物理数据。预测warp/patch有效支持来自预测，不使用GT mask、反向网络或新采样。这是显式修改的下游objective消融，不声称原论文STE训练配方未变，也不声称已修复一个被证明的全局根因。

实际服务器CPU8/8及CPU数据/模型集成准入通过。原始NPZ严格检查finite[0,1]；已知原生插值和warp的内部张量仅容许有限机器舍入余量，不clamp、不改变数值/梯度。初版饱和白图误拒绝与修复证据保留。

phase0恢复模型/Adam/scheduler但不step，固定8批×两生成器共16个TRAIN观察，按82完整参数集、unused作零计算范数；共同λ=1/median(||g_census||/||g_native_photo||)=0.00018879906228896475，实际70个connected有限梯度均验证。参数在任何更新前冻结，不用GT/验证/真实分数校准。四臂各一次真实更新及独立模型/Adam恢复通过。后续每臂固定200步，完整528窗验证，仍需两方法总体与共同活跃EPE都改善、各物理层退步不超过5%，不自动长训或真实评分。
